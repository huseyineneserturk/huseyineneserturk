## Featured Project

### Agentia — Mobile-First AI Agent Orchestration Platform

> *"Your City, Your Rules, Your Workforce."*

[![Repo](https://img.shields.io/badge/View_Repository-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/huseyineneserturk/Agentia)
![CI](https://img.shields.io/badge/CI-Test_%26_Lint-2088FF?style=for-the-badge&logo=github-actions&logoColor=white)
![CD](https://img.shields.io/badge/CD-Docker_Build-2496ED?style=for-the-badge&logo=docker&logoColor=white)

**Agentia** lets users create, run, and share their own AI agents — no complex flow diagrams required. Unlike n8n, Make.com, or Zapier, it delivers a fully **mobile-native** experience, elevated by a gamified **Agent City** interface. *(Graduation Project, 2026)*

**Highlights**

- **Agent Builder** — Create an AI agent in minutes through a 4-step wizard (identity, personality, capabilities, publishing)
- **Agent City** — A gamified, zoom-and-pan city map where each island represents an agent category
- **Pipeline System** — Chain multiple agents so each one's output feeds the next, with sharing and forking
- **Agent Hub** — A marketplace to discover, rate, and fork agents, with a usage-based credit system (70/30 revenue split)
- **8 AI Tools** — Web search, summarization, code execution, URL reading, data transformation, and more, powered by **LangChain + Google Gemini**
- **Webhook Triggers** — Securely trigger pipelines from external systems via unique secret tokens

**Architecture**

A microservices system orchestrated with Docker Compose (10 services), deployed via Kubernetes, with full CI/CD and observability.

| Layer | Technology | Details |
|-------|-----------|---------|
| Mobile | Flutter 3.x (Dart) | Riverpod, go_router, Dio |
| Core API | Java 17 / Spring Boot 3.x | JPA, Flyway (16 migrations), JWT, Redis, Swagger |
| AI Worker | Python 3.11 / FastAPI | LangChain, Celery, Google Gemini |
| Web Dashboard | Next.js 14 / TypeScript | Recharts, JWT auth |
| Data | PostgreSQL 16 · Redis 7 | RLS support, Celery broker |
| Observability | Prometheus + Grafana · k6 | Custom dashboards, 100-user load tests |
