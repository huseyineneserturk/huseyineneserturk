## Selected work

### Agentia

My graduation project: a mobile application for creating AI agents and connecting them into pipelines. A Flutter client connects to a Spring Boot API and Python workers. The project covers agent configuration, asynchronous task execution, pipeline management and usage credits.

**Java · Spring Boot · Flutter · FastAPI · Celery · PostgreSQL · Redis**  
[Project overview](https://www.huseyineneserturk.com/en/projects/agentia) · Source code is private.

### Cradlecrown

A real-time strategy game that runs in the browser. Players develop an economy, command armies and choose civilizations as they advance through the ages. The browser and Node.js server share the same simulation code for single-player and online matches.

**TypeScript · HTML5 Canvas · Node.js · Socket.IO**  
[Play](https://cradlecrown.com/) · [Project overview](https://www.huseyineneserturk.com/en/projects/cradlecrown) · Source code is private.

### Scanex

A mobile optical answer-sheet reader. It generates PDF forms, reads marked answers from camera images, grades them and exports results to Excel. The OMR processing is written in Dart, with ML Kit for text recognition and SQLite for local storage.

**Flutter · Dart · ML Kit · SQLite**  
[Source code](https://github.com/huseyineneserturk/Scanex)
